# 메인 최신 웹툰과 선택형 홍보 팝업

운영에는 적용하지 않았다. 로컬 마이그레이션은
`20261112110000_add_webtoon_promotion.sql` 한 개를 추가한다.

## 동작과 관리자 사용

메인 하단은 공개 작품의 공개 회차를 published_at 내림차순으로 한 개 표시한다.
동일 시각은 회차UUID로 고정 정렬한다. 표지·작품명·회차명·작품 소개180자와
해당 회차 뷰어 링크를 제공한다. 준비된 콘텐츠·표지가 없거나 공개 회차가
없으면 영역 전체를 숨긴다. 이미지와PDF를 같은 방식으로 지원한다.

기존 `/admin/webtoons`의 '선택형 웹툰 홍보 팝업'에서 공개 회차, 안내 문구280자,
시작/종료일(KST), 활성화를 저장한다. DB 기본값은 비활성화이며 관리자가 명시적으로
켠 경우에만 공개 기간 내 노출한다. 시작 포함·종료 제외다. 설정은 singleton이고
버전으로 동시 편집 충돌을 거부한다. 설정 새로고침으로 공개 회차 목록을 갱신한다.

공개일은 공개 전환 시 DB statement_timestamp로 기록한다. 공개 상태의 제목 수정은
순서를 바꾸지 않는다. 비공개 후 재공개는 새 공개 시각이다. 기존 회차의 실제
공개 시각은 과거에 저장하지 않았으므로 migration 시 공개 회차 updated_at을
대체값으로 사용한다. 이를 과거 실제 공개 시각 복원이라고 주장하지 않는다.

팝업은 루트 레이아웃에 유지되며 탭 세션당 한 번 노출한다. 닫기/ESC/지금 보기 후
페이지 이동·새로고침에서 다시 열지 않는다. '오늘 하루 보지 않기'는 서버 시간
차이를 반영해 한국 날짜만 localStorage에 저장한다. 기기 시간대와 무관하며
한국 자정을 넘기면 날짜가 만료된다. 이미 노출한 같은 탭 세션에서는 다음 날에도
세션 중복 억제가 우선한다. 새 탭/세션은 그날 숨김 설정을 확인한다. 브라우저 저장소
차단 시에는 메모리 상태로 페이지 이동 중 반복을 막는다. 기기 간 동기화는 없다.

관리자·로그인·인증·테스트 로그인 및 회차 뷰어에서는 팝업을 표시하지 않는다.
모바일 팝업은 최대48dvh, 내부 스크롤, 배경 조작을 허용하는 비모달 dialog다.
접근성 이름·설명, 첫 닫기 버튼 포커스, ESC, 포커스 복원, 키보드 포커스 표시와
최소44px 액션을 제공한다. 비모달이므로 키보드 포커스를 가두지 않는다.

## 공개 상태와 표지 보안

공개 API/RPC는 공개 작품+공개 회차+ready 콘텐츠/표지를 매번 검사한다.
비공개/삭제는 즉시 API 결과에서 제외한다. 작품/회차 공개 취소 및 삭제 trigger가
선택된 홍보를 비활성화하므로 재공개만으로 홍보가 재개되지 않는다.
열린 클라이언트는15초마다 및 경로 이동/탭 복귀 때 재검사하고 실패 시 숨긴다.
종료일은 클라이언트 타이머로 닫는다. 따라서 이미 열린 카드/팝업의 철회 반영은
다음 재검사까지 최대 약15초+요청 지연이며, 이미 받은 이미지는 회수할 수 없다.

홍보 표지는 `/api/webtoons/promotion/cover/:episodeId` 전용 경로에서 원본 표지를
최대360x480 WebP로 새로 재인코딩한 별도 이미지다. EXIF/원본 파일은 전달하지 않는다.
생성 전/후 공개 상태와 표지ID를 재검사하고 private/no-store로 반환한다. 별도 Storage
버킷을 만들거나 원본 읽기/서명 권한을 넓히지 않는다. 비공개 원본/PDF 접근 권한은
기존 방식 그대로다. 광고용 이미지도 공개 취소 후 같은URL로 다시 받을 수 없다.

## 스키마·API와 운영 승인 범위

- webtoon_episodes.published_at, 공개 회차 날짜 인덱스, 공개 전환 trigger.
- webtoon_promotion 1행: 대상 FK(on delete set null), 문구, 시간, enabled=false,
  version, updated_at. RLS enabled, anon/authenticated 테이블 접근·변경 불가.
- webtoon_promotion_card(uuid): service_role 전용; 안전한 공개 요약만 반환.
- webtoon_promotion_payload(): anon/authenticated/service_role 읽기 허용,
  고정 search_path의 security definer로 공개 요약만 반환. 설정 원문·object_key 미노출.
- 관리자 GET/PUT /api/admin/webtoons/promotion: 실제 사용자토큰·role·suspension 검사 재사용.
- 공개 GET /api/webtoons/promotion, 전용 축소 표지 경로. no-store.

운영 반영 시 기존 두 웹툰 migration 다음에 이 migration을 별도 검토·승인한다.
기존 DB/Storage 백업·복구 리허설 게이트는 webtoons-release.md 그대로다. 이번 기능의
Storage/Nginx 변경은 없다. 코드 롤백은 설정을 먼저 비활성화하고 기존 릴리스로
전환하되 추가 테이블·컬럼·trigger는 보존한다. 일반 검증 빌드 artifact는 배포 금지다.

## 재현 검증

검증된 격리 로컬 앱을 실행한 뒤 프로젝트 Node22로
`scripts/webtoons/promotion-check.cjs` 실행. 기존 합성 이미지/PDF 도구를 재사용한다.

공개일 정렬/제목 수정, 이미지·PDF 대상, 실제 축소 표지 치수/Storage 직접 접근 거부,
기본 비활성화, 비관리자 거부, 예약·만료, 임시저장·작품/회차 공개 취소·삭제와
재공개 후 자동 홍보 미재개를 API에서 확인한다. Chrome390x844와 미국 시간대에서
실제 관리자 저장, 메인 카드·회차 이동, 닫기/ESC/포커스, 페이지 이동·새로고침 억제,
오늘 숨김·전날 설정 만료·KST 자정 경계, 기간 만료·공개 취소 후 열린 팝업 제거,
공개 회차 없을 때 영역 미표시를 확인한다. 모든 탭의 JS 오류를 수집한다.

합성 계정/state/스크린샷은 Git 밖 parent에 보관한다. 실제 회원·운영 파일은 사용하지 않는다.
